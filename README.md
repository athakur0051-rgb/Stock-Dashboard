# Stock-Dashboard
# 📈 Real-Time Stock Market Dashboard

## Overview
This is a web-based financial dashboard that tracks and visualizes live stock market data. Built entirely in Python using Streamlit, it allows users to input any stock ticker symbol (e.g., AAPL, TSLA, GOOG) and instantly view interactive candlestick charts and historical pricing data.

## Features
* **Live Data Fetching:** Automatically pulls real-time financial data using the Yahoo Finance API.
* **Interactive Visualization:** Displays dynamic candlestick charts (Open, High, Low, Close) built with Plotly.
* **Custom Time Periods:** Users can filter data by 1 month, 3 months, 6 months, or 1 year intervals.
* **Raw Data Table:** Displays a quick-view table of the most recent market closing metrics.

## Technologies Used
* **Python 3**
* **Streamlit** (Web framework and UI)
* **yfinance** (Financial data extraction)
* **Plotly** (Interactive charting)
* **Pandas** (Data manipulation)
